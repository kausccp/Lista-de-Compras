# 🛒 Minha Lista de Compras

## 📌 Sobre o projeto

O **Minha Lista de Compras** é uma aplicação web desenvolvida para facilitar a organização de compras do dia a dia. O sistema permite que o usuário adicione produtos à lista, defina a quantidade desejada e remova itens quando necessário.

A aplicação possui uma interface simples, moderna e intuitiva, proporcionando uma experiência prática para o gerenciamento dos produtos.

## ✨ Funcionalidades

* ➕ **Adicionar produtos:** permite inserir produtos na lista de compras.
* 🔢 **Definir quantidades:** possibilita informar a quantidade de cada item.
* 🗑️ **Remover produtos:** permite excluir itens da lista facilmente.
* 📋 **Visualizar produtos:** exibe os produtos cadastrados e suas respectivas quantidades.
* 🔢 **Contagem de itens:** apresenta a quantidade de produtos cadastrados na lista.
* 🎨 **Interface intuitiva:** design organizado para facilitar a utilização.
* 📱 **Layout responsivo:** interface pensada para diferentes tamanhos de tela.

## 🖥️ Demonstração

A interface da aplicação apresenta um formulário para adicionar novos produtos, uma lista com os itens cadastrados e botões para remover produtos.
